Design distinctions: Stat Info Progress Status Summary Custom

All variants use the same Section V1 → SharedBanner V2 → BannerRow → BannerCell architecture. Column dividers and horizontal row dividers are optional; primary content is always visible; secondary rows collapse as a group. This is a design preview only—not a deployment or a change to the previously approved GameSummaryBanner V1.
