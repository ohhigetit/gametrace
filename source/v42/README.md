# GameTrace V42 — consistent review and family Live Feed

Approved release: all pending UI refinements and the approved family-viewer feed. Built from the reviewed V41 runtime with the Create Game deletion fix. No user data is seeded, reset, or deleted by deployment.

Build: `python3 source/v42/build.py`. Source: `base.html`, `refinements.js`, `live-feed.js`, `refinements.css`. Generated `index.html`, `source/v42/GameTrace_V42.html`, and `templates/current/GameTrace.html` must be byte-identical. Earlier builders are historical and do not generate this release.

- Home Court is the visual standard. One uppercase, bold, letter-spaced approved subtitle per applicable page; no subtitle on Live Game, Event Details, Edit Game, Settings or Menu. Georgina appears in the Home Court title and persisted identity fields, not list metadata/subtitles. Form defaults retain existing player identities.
- Current Game is a filled banner with score, progress and Open/Resume; Delete is inside Edit Game. Game Details puts Scoreboard on the title row. Performance shows PTS/REB/AST/STL with other stats collapsed. Timeline checkboxes share one row. Recorded Plays/Score Journey are exclusive accessible tabs; full-width Add buttons, tap-to-edit rows and direct pointer/keyboard dragging use the original validated timestamp engine.
- Log Session/New Goal/Add Note/Add Event move to title rows. Notebook search is removed while filters remain. Schedule uses Upcoming with Event type/From/To/Team/Calendar source filters; no Calendar view; Past Events is last. Calendar import remains inside Add Event. Wall trophy centering and inline Show/dropdown are standardized.
- Live title opens metadata editing. Game-progress dialogs anchor lower-left. The physical controller and portrait camera pipeline remain the tested baseline.
- Family Huddle → Watch Game opens an authenticated family-only viewer with score, progress, stats and latest-first recorded plays. Viewer reads use `gt_records` under existing RLS; they do not mutate tracker data or publish public links. Foreground tracking and watching poll every five seconds. Existing local-first save, expected-version writes, conflict review and retry-on-reconnect remain. Delayed/failed reads retain the last snapshot with a connection warning; rejected access clears it.

Live Feed needs no new database migration. Existing Family Huddle sign-in and game sharing must be configured; existing-record sharing review is preserved. Optional general-note/recurring/cancelled Schedule sync requires migration 007 after 006; local records remain safe before activation. Setup pages are included. Email delivery remains a separate service/scheduler requirement and is never reported ready without its backend. No live SQL or private administrative configuration was executed for this release.

Validation: core/timing/backup, training/camera-preservation, journey, family sync, UI regression and real PostgreSQL/RLS suites; browser review with isolated sample records, never production records. Physical iPhone camera and two signed-in family devices remain user acceptance checks. The standalone approved feed demo is not deployed.
