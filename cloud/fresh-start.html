Fresh Start setup

This small update allows the Owner/Admin training and trophy reset, plus Family Trophies and Next Steps to sync with your existing family. Existing games, training, videos, memberships and invitation codes are preserved.

  1. Tap Copy setup SQL.
  2. Open your existing GameTrace project in Supabase → SQL Editor → New query. Paste and Run.
  3. After “Success. No rows returned,” refresh GameTrace on each family device and use Family Cloud → Sync now.
  4. To reset your records, return to GameTrace → Family Cloud → Reset trainings and trophies. Review the scope and confirm.

Until this update is installed, the shared reset stays disabled. This setup does not clear any records. After installing it, open GameTrace → Family Cloud → Reset trainings and trophies. Games and training keep syncing. Do not rerun the original family setup or reset query.
