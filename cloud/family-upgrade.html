Update Family Cloud

One setup update for your existing GameTrace Supabase project.

This preserves families, games, training and recordings. Each family creator becomes its Owner. Existing invitation codes expire; Owners and Admins can generate new 7-day codes afterward.

  1. Tap Copy setup SQL below.
  2. In Supabase, open GameTrace → SQL Editor → New query. Paste the complete SQL and tap Run. You should see “Success. No rows returned.”
  3. In Authentication → URL Configuration, allow this development redirect: https://development--game-trace.netlify.app/?family_auth=1. This lets confirmation and password-reset emails return to GameTrace.
  4. Refresh GameTrace, open Family Cloud, and tap Check family connection or Sync now.

Show SQL / manual copy

If iPhone copying is blocked, expand “Show SQL,” tap the text, then Select All → Copy. In the SQL Editor, use the iPhone three-finger paste gesture if long-press paste does not appear.

This update belongs in the existing project; do not run the original schema again.
