# GameTrace templates

Use [current/README.md](current/README.md) for new work. The authoritative current specification is [approved design and development](../docs/GameTrace_Approved_Design_and_Development.md), with the current release snapshot in [current/release-manifest.json](current/release-manifest.json).

- [Current application template](current/README.md): source composition, build and locked behavior.
- [Feature/change template](current/change-template.md): bounded implementation requests and acceptance criteria.
- [Regression matrix](current/regression-matrix.md): behavior and data-integrity checks.
- [Release checklist](release-checklist.md): destination, authorization and verification.

`v24/`, `v25/` and `v26/` are frozen historical templates. Their status statements apply to their original release dates. Do not build new releases from them or copy their old runtime over the current root app.
