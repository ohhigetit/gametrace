# GameTrace V14 — approved release

Approved by Mike on October 29, 2026.

Includes the reviewed Electric Green controller, native basketball and whistle symbols inside REB/FOUL, unified divider hierarchy, aligned Touch/Pass content, clearer action symbols, numeral-first shooting labels and stronger hold feedback. Existing V13 recording, court/bench states, recent-action editing, expandable stats, backups and save recovery remain available.

Validation: 90 functional checks and eight phone/theme layouts, including saved-game compatibility with V13. Physical iPhone thumb-reach and Safari testing remain useful.

Deployment: development first, verified before promotion to main. Netlify serves the standalone index.html from the repository root.

The previous production tracker is preserved at /legacy/. It uses its original browser-storage keys. Existing records from that tracker are available there; they are not automatically migrated into V14. V14 uses the V11 database/backup schema. No browser records are deleted by this deployment.

Period/timestamp accounting and recorded-data Game Circles remain future milestones.
